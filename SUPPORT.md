# SocketCore Support

SocketCore is a reusable Node.js WebSocket engine maintained in the Vib Tools project context. For setup and behavior, start with the [documentation index](docs/README.md).

**A reusable WebSocket core for real-time Node.js applications.**

If the repository's GitHub Issues tab is enabled, use it for reproducible bugs and feature requests that do not contain sensitive information. For questions about package behavior, include the package version, Node.js version, a minimal reproduction, and the exact command or API call. Remove tokens, personal data, and private URLs before sharing logs.

Use the private reporting instructions in [SECURITY.md](SECURITY.md) for vulnerabilities; do not post them as public issues.

## Project Limits

The repository's 1,000- and 2,000-client measurements are synthetic loopback studies, not a production support guarantee. No production SLO or support response-time commitment has been published. Review [docs/LOAD_TESTING.md](docs/LOAD_TESTING.md) for measurement scope and limitations.
