# Getting Started

SocketCore is a Node.js CommonJS library, not a hosted WebSocket service.

1. [Requirements and installation](installation.md): Node, npm, supported package entry.
2. [Verified quickstart](quickstart.md): build an HTTP server and connect a Node client.
3. [Configuration reference](../reference/configuration.md): limits, Origin, deadlines.
4. [Integration guide](../guides/integration.md): embed in an existing HTTPS application.

For the shipped standalone demonstration, use [the existing user guide](../USER_GUIDE.md). This documentation focuses on integration by developers.
